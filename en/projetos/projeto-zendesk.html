Smart Support App for Zendesk

A native app in the ticket sidebar that uses AI to classify tickets, draft replies and build escalation scripts, reducing the time agents spend filling in and interpreting each ticket by hand.

▶ Try the demo
How the project started

From manual forms to automatic classification

Problem

Time lost on manual classification

Agents spent significant time filling in forms and classifying each ticket (priority, reason, product) according to the SLA policy. A repetitive, manual process prone to inconsistency between agents.

→
Solution

An app with AI built into the ticket

A native Zendesk app, integrated with the OpenAI API, that reads the ticket description, classifies it automatically, suggests a title, generates a technical diagnosis, drafts replies to the customer and builds the escalation script for the tier-3 team.

→
Result

Faster, standardized replies

Shorter response times and more consistent classification and communication across agents, with the whole analysis applied to the ticket in one click.

Under the hood

Technologies used

Zendesk Apps Framework
Native app embedded in the ticket sidebar (ZAF SDK).
React / JavaScript
App interface, with state and tabs for analysis, message and script.
OpenAI API (GPT-4o-mini)
SLA classification, technical diagnosis and text generation.
Zendesk REST API
Applying fields, linking organizations, notes and comments.
